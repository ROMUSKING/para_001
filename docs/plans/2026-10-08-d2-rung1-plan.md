# D2 Rung-1: learned ranker with answer endpoints (frozen design)

**Status:** DRAFT for peer review — no training until reviewed.
**Predecessors:** Rung-0 G2 fail (BM25 keeps 26%); bridge v2 FAIL with +30pp/+20pp
descriptive contrast; longest-first beats BM25 on EM (suggestive, not established).
**Question:** does a learned ranker on deployment-valid features beat BM25 on
recall *and* hold answer quality under the frozen reader?

## 1. Model and supervision (frozen)

- **Model:** L2 logistic regression on per-paragraph features: BM25, TF-IDF cosine,
  length (tokens), position index, title-match count (shared tokens between
  question and title), entity-match count (shared tokens between the paragraph
  and `entity_spans(question)`). All six computable from question + visible
  texts/titles only (boundary test pins this: shuffling supports, answers,
  aliases, decompositions must not move features or rankings).
- **Supervision:** support labels as binary targets (privileged, training only —
  legitimate supervised signal, same role as before).
- **Training:** tuning questions only (2000 frozen registry ids), class-balanced
  sample weights, C selected from {0.1, 1.0, 10.0} on **tuning** 5-fold CV
  **grouped by question** (no paragraph of a question spans folds; scaling, if
  any, fit inside each fold). CV is the C-selection rule only, not evidence of
  generalization (the tuning set already chose best-fixed earlier).
- **Selection:** rank by predicted P(support), top-k (ties → lower index).

## 2. Evaluation (frozen)

- **Recall set:** same 300 frozen validation ids; k=4,8; BM25 + longest-first
  retained as deployable comparators; oracle privileged reference.
- **Answer set:** frozen Phi-4-mini-instruct reader, frozen v2 prompt/template,
  same 300 ids, oracle/BM25/longest/learned sets at k=4,8 (1800 + 600 calls).
- **Primary gate:** learned beats BM25 by ≥5pp recall at k=4 or k=8 (one-sided
  paired Wilcoxon). **Co-gates:** learned non-inferior to longest-first on
  recall (margin −2pp) and non-inferior to BM25 on EM (margin −2pp). All six
  comparisons form one Holm family using 95% two-sided Wald CIs on paired
  differences (recall and EM in pp); a bound passes when its Holm-adjusted lower
  edge clears its margin. A recall win with EM collapse is reported, not passed.
- **Exploratory label (review):** these 300 ids served the bridge and R2; the
  learned arm is new and untuned on them, but the plan was selected after seeing
  them. Nominal p-values only — a confirmatory claim needs an untouched set.
- **Compute split:** training + recall eval on CPU (sandbox); reader EM eval on
  L4 (frozen inference, ~2400 calls, single session, stop after).

## 3. Boundaries

No co-state, no critic, no H2 content. No hyperparameter exploration beyond the
frozen C grid. No reader/prompt changes (v2 protocol). Failure closes the
learned-ranker formulation for these features; it does not authorise neural
rankers without a new reviewed plan.
