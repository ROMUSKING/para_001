2. Technical Validation and Critical Audit
2.1 Audit of Project para_001 (AdjointRWM)
A. The Empirical Baseline Challenge (Linear Ridge Dominance)
* Reported Finding: In Milestone B3b on the 500-episode DROID stratified shard (8,559 test windows), AdjointRWM achieved a normalized test proprioception RMSE of $0.3720 \pm 0.0074$, outperforming four parameter-matched neural competitors:
   * vs. dreamerv3_rssm ($0.6719 \pm 0.0059$): $-44.62%$ relative error
   * vs. tdmpc2 ($0.5580 \pm 0.0088$): $-33.33%$ relative error
   * vs. dino_wm ($0.4925 \pm 0.0248$): $-24.53%$ relative error
   * vs. vjepa2_ac ($0.4915 \pm 0.0222$): $-24.37%$ relative error
* Critical Vulnerability Identified: Non-parametric and simple linear baselines decisively outperformed AdjointRWM on the exact same test split:
   * persistence (holding current joint state): $\text{RMSE} = 0.2021$ ($+84.13%$ relative to AdjointRWM; classified as inconclusive)
   * ridge (linear regularized regressor): $\text{RMSE} = 0.1002$ (Ridge has $73.1%$ lower error than AdjointRWM; AdjointRWM has $3.71\times$ the error of Ridge)
* Diagnostic Interpretation: In short-horizon (4-step) manipulation benchmarks under quasi-static conditions, robotic joint trajectories are heavily dominated by linear inertia and autoregressive momentum. Therefore, claimed "supremacy" over neural baselines does not demonstrate overall predictive superiority for robotic control.
B. Causal Action Coupling Interpretation
* Reported Finding: In action-shuffling experiments, AdjointRWM's error increased from $0.3720$ to $1.1875$ (a $3.19\times$ ratio), compared to $1.69\times$ for DreamerV3 and $2.50\times$ for TD-MPC2.
* Audit Finding: Ridge regression achieved an action coupling ratio of $8.54\times$ ($0.1002 \to 0.8554$). Permutation testing is an action-sensitivity diagnostic, not a formal proof of causal identification. Formal do-calculus interventions, matched counterfactual trajectory rollouts, and physical closed-loop evaluations are strictly required.
C. Data Integrity and Site Accounting Discrepancy
* The executive summary reports evaluation on "8,559 held-out test windows from 50 episodes across 14 robotics laboratories."
* However, the detailed site table lists only 12 sites, and the sum of windows across the listed sites equals 29,078—a $3.40\times$ discrepancy. This requires immediate reconciliation via a cryptographic window-level manifest.
D. Hardware and Latency Realities
* Reported Claim: $6.90\text{ ms}$ inference latency on an NVIDIA L4 GPU within a "35W edge envelope."
* Audit Finding: The NVIDIA L4 is a 72W datacenter PCIe accelerator, and the $6.90\text{ ms}$ figure was benchmarked at batch size 128 (measuring throughput, not single-robot real-time control). Real-time robotic control requires batch-1 profiling on embedded System-on-Chips (SoCs) such as the NVIDIA Jetson AGX Orin ($15\text{–}60\text{ W}$) or Jetson Thor ($40\text{–}130\text{ W}$), including sensor ingestion and encoder overhead.
E. GitHub Actions CI Failure on Commit de6c070
* The CI harness failed due to:
   1. Directory Immutability Violation: Colab runner ran consecutive probe jobs without unique session timestamps, triggering collisions against immutable run directories.
   2. Hardcoded Drive Paths: Code asserted /content/drive/MyDrive/..., which is absent on GitHub ubuntu-latest runners.
   3. Cryptographic Hash Mismatch: Commit modified code without updating prereg/prereg_hashes.json or logging deviations in prereg/deviation_log.yaml.

3.1 Resolving the "When to Recurse" Dilemma
* The Problem in Fractal World Models: The fractal framework proposes multi-scale recursion across scales $s$, but lacks a mathematical stopping rule or compute allocation criterion.
* The Adjoint Solution: The Pontryagin co-state $\lambda(t) = \nabla_{z} J$ from para_001 measures the exact first-order sensitivity of the task objective to state perturbations.
   * Low Sensitivity ($|\lambda(t)| < \tau_{\text{nominal}}$): The system operates at coarse scale ($s_{\text{coarse}}$), utilizing contractive Zoom-Out ($A$) and nominal linear kinematics.
   * High Sensitivity ($|\lambda(t)| \ge \tau_{\text{rescue}}$): The system invokes the Analytical Rescue Interface, triggering Zoom-In ($G$), activating high-resolution visual tokens, and evaluating non-linear adjoint rollouts.
3.2 Resolving the "Edge Compute Wall" in Robotics
* The Problem in para_001: Running full neural world models at 100Hz on 20W–50W robot payloads causes thermal throttling and compute exhaustion.
* The Adapter Solution: Apply the Hierarchical Multi-Adapter Serving Engine to robotics:
   * Freeze a shared cross-embodiment spatial backbone in 4-bit NormalFloat (NF4) or FP8 on the robot's onboard Jetson Orin/Thor.
   * Deploy lightweight, task-specific Low-Rank Adapters (rank $r=16$, $\approx 40\text{ MB}$) for distinct manipulation primitives (e.g., drawer opening, tool insertion, compliant wiping).
   * Use the pointer hot-swapping runtime to swap task policies dynamically in $<1\text{ ms}$ based on the high-level intent classifier without reloading base weights.
3.3 Resolving the Classical Baseline Anomaly (Ridge vs AdjointRWM)

We define the unified system: HARP (Hierarchical Adjoint-Reduced Policy & World Model).
4.1 State Space and Factorization
The continuous latent state is structured as an SCM-inspired Coherence Field $C(t) = (R(t), S(t))$:


* $R(t) \in \mathbb{R}^{d_R}$: Global invariant context register (task objective, robot embodiment kinematic parameters, environmental physics invariants).
* $S(t) = {s_1(t), s_2(t), \dots, s_K(t)}$: Dynamic entity slots representing the robot end-effector, target objects, and obstacle bounding volumes.
4.2 Dynamics and Sensitivity Formulation
Continuous-time latent evolution is governed by: $$\dot{z}(t) = f_{\text{hybrid}}(z(t), u(t); \theta) = F z(t) + G u(t) + \Phi_{\text{LoRA}}(z(t), u(t); W_0 + \frac{\alpha}{r}BA)$$


The Hamiltonian for downstream task objective $\mathcal{L}(z(T))$ with running stage cost $L(z, u)$ is: $$H(z, u, \lambda) = L(z, u) + \lambda(t)^\top f_{\text{hybrid}}(z, u)$$


The backward adjoint co-state equation provides exact sensitivities: $$\dot{\lambda}(t) = -\nabla_z H = -\nabla_z L(z, u) - \left[\frac{\partial f_{\text{hybrid}}}{\partial z}\right]^\top \lambda(t), \quad \lambda(T) = \nabla_{z} \mathcal{L}(z(T))$$
4.3 Adaptive Resource Allocation Decision Matrix
At each control step $k$, compute the epistemic uncertainty $\sigma_k$ and the adjoint sensitivity magnitude $|\lambda_k|$:


* Tier 0 (Nominal Kinematic Pass): If $|\lambda_k| < \tau_1$, evaluate only the linear state-space update ($F z + G u$). Latency: $<0.05\text{ ms}$. Power: minimal.
* Tier 1 (Amortized Adjoint Pass): If $\tau_1 \le |\lambda_k| < \tau_2$, activate the feedforward neural residual $\Phi_{\text{LoRA}}$ using proprioceptive inputs only. Latency: $\approx 0.70\text{ ms}$.
